# Reuse existing server save names

Add a clickable list of existing server saves to Save to server. Choosing a name fills the Save name field without loading that file or changing workspace content. Preserve optional overwrite passwords from the current PR: password-protected saves require the existing password; unprotected saves can optionally acquire one.

Fetch only public library metadata. Never prefill or retain a password when switching destinations. Show selected name and overwrite protection status, support typing new names, and keep new-name saves usable if listing fails. Ignore late responses after closing/replacing the dialog. Verify selecting a protected name and overwriting with its password; regression-check selection changes only the name.
